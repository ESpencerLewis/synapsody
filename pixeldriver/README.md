# Synapsody — Pixel Driver (Physical Exhibit Prototype)

A prototype exploring a physical counterpart to [Synapsody](../)'s digital brain visualization: an LED bank driven by live EEG data, propagated through fiber-optic cable intersected by 3D-printed clear synapse structures. Each color represented a different brainwave range (alpha, delta, etc.), giving the reactive synapse visualization a physical, sculptural form instead of a screen-based one.

This was an early-stage prototype for a physical exhibit build-out of the Synapsody concept.

## Status

Like the main Synapsody project, this is part of ongoing research being evaluated for IP protection, so implementation and driver logic are not published in this repository.
