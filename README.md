# Synapsody

![preview](media/intro_preview.gif)

An interactive music experience for exploring your own brain activity. Participants wear an EEG headset, and relaxing or focusing changes the music in real time while a 3D brain visualization responds.

Synapsody is a **1-2 player music game** built in TouchDesigner.
